## 🎯 **HOW TO UPLOAD PLOTS AFTER DEPLOYMENT**

### **Step 1: Access Owner Dashboard**
1. Go to your deployed site: `https://your-site.netlify.app`
2. Click **"Owner Sign In"**
3. Login with owner credentials
4. Access the dashboard

### **Step 2: Upload New Plots**
1. Click **"Upload Plot"** in sidebar
2. Choose **Premium** or **Normal** plot type
3. Fill in plot details:
   - Plot number
   - Village name
   - Area name
   - Plot size
   - Facing direction
   - Price (optional)
   - Description
4. **Upload image** (drag & drop or click to browse)
5. Click **"Upload Plot"**

### **Step 3: Manage Existing Plots**
1. View all plots in dashboard
2. **Edit** existing plots
3. **Delete** plots if needed
4. **Update** prices and details
5. **Change status** (Available, Sold, Reserved)

## 🔧 **TROUBLESHOOTING**

### **Common Upload Issues:**

**"Image too large"**
- **Solution:** Compress image to under 4MB
- **Tools:** Online image compressors

**"Plot already exists"**
- **Solution:** Check plot number and village name
- **Fix:** Use different plot number or edit existing

**"Upload failed"**
- **Solution:** Check internet connection
- **Retry:** Refresh page and try again

### **Performance Tips:**
- **Optimize images** before upload (recommended: under 1MB)
- **Use modern formats** (WebP when possible)
- **Upload during off-peak** hours for faster processing
